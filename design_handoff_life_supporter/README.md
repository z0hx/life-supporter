# Handoff: life-supporter (PWA — メモ + 単価計算)

## Overview
life-supporter は個人の日常生活を支援するモバイル専用 PWA。初期リリースは2機能:

1. **メモ** — TVで見た行きたい店・場所・買い物リストを一元管理(カテゴリ+タグ、グルーピング表示、ソート)
2. **単価計算** — 店頭で複数商品の単価(100g/100ml/1個/1枚あたり)を比較し最安を判定、履歴保存

ホーム画面をハブとし、将来機能(家計簿・リマインダー等)の追加枠を常設する。

## About the Design Files
このバンドル内のファイルは **HTMLで作成されたデザインリファレンス** であり、そのまま本番投入するコードではない。タスクは、これらのデザインを **ターゲットのコードベースの既存環境(React / Vue / Svelte 等)とその慣習・ライブラリで再現実装すること**。環境が未定の場合は、この規模のローカルファーストPWAに適したフレームワークを選定して実装する(推奨: Vite + React or Svelte + TypeScript、サーバー不要)。

- `design-mocks.dc.html` — 画面デザインモック(採用案+検討過程)。ブラウザで開ける。
- `requirements-spec.dc.html` — 要件・仕様書(v1.0、印刷可)。**実装要件の正はこのドキュメント**。
- `doc-page.js` — 仕様書の表示に必要なランタイム(実装対象ではない)。

## Fidelity
**High-fidelity (hifi)**。採用デザインは確定済み — モック内 **ターン3(3a/3b/3c)とターン1の案1c** が採用スタイル。色・角丸・タイポグラフィ・余白はモックの値をピクセル基準で再現すること。
注意: モックにはターン1の 1a / 1b(不採用案)、ターン2の 2a/2b/2c(1aスタイルでの検討版)も含まれる。**実装対象は 1c スタイルのみ**。3a と 3b はメモ一覧の代替UI(常設バー vs ボトムシート)であり、どちらを採用するか未確定 — 実装前に確認するか、3a(常設コントロールバー)を既定とする。

## Screens / Views
詳細レイアウトは `design-mocks.dc.html` の各画面を参照。構成は仕様書4章と同一:

1. **ホーム**(1c ターン1) — あいさつ+日付 / メモカード(未完了先頭2件プレビュー+件数)/ 単価計算タイル / 「近日公開」タイル(opacity .5)/ 前回比較結果のヒントバー / 設定リンク
2. **メモ一覧**(3a または 3b) — グルーピング切替(カテゴリ/タグ/なし)+ソート切替(作成日時/更新日時/手動)/ グループ見出し(カテゴリ色+件数+折りたたみ)/ メモ行(丸チェック+タイトル+タグチップ+相対更新時刻)/ 下部固定「＋ メモを追加」ボタン
   - 3a: コントロールを画面上部に常設(セグメント+ソートドロップダウン)
   - 3b: ヘッダー「☰ 表示」ボタン → ボトムシート(グルーピングセグメント+並び順ラジオ)
3. **メモ追加・編集**(3c、モーダル) — タイトル入力(フォーカス時アクセント枠)/ カテゴリ選択チップ(1つ、+追加可)/ タグ入力(選択済みチップ ✕ 付き+既存タグ候補+新規作成)/ 優先度セグメント(ふつう/高)/ 補足メモ / 作成・更新日時表示 / ヘッダーに キャンセル・保存
4. **単価計算**(1c ターン1) — 単位モードチップ(100g/100ml/1個)/ 商品カード(価格・内容量の2入力 → 単価を即時表示)/ 最安カードはアクセント枠+「🎉 こっちがお得!」バッジ+差額%表示 / 「＋ 商品をくらべる」/ クリア・履歴に保存
5. **履歴一覧** — 保存名+日付リスト、タップで比較状態を復元(モック未作成 — メモ一覧と同じリストパターンで実装)
6. **設定** — カテゴリ管理 / アーカイブ設定 / エクスポート(JSON+共有シート)・インポート・全削除 / バックアップリマインド(モック未作成)

## Interactions & Behavior
- メモ: チェックで完了(取り消し線+グループ末尾へ)、スワイプ or メニューで削除、手動ソート時はドラッグ並べ替え。優先度「高」はグループ内先頭固定。完了済みは30日で自動アーカイブ(設定可)
- グルーピング/ソートの選択状態は永続化し次回起動時に復元
- タグごと表示: 複数タグのメモは各グループに重複表示、タグなしは「タグなし」グループ(淡色)
- 単価計算: 入力毎にリアルタイム再計算。単価 = 価格 ÷ 内容量 × 基準量(小数第1位表示)。最安商品を自動ハイライト+「◯% お得(差 ¥x/単位)」
- 数値入力は `inputmode="decimal"` で数値キーパッドを表示
- 起動から入力可能まで1秒以内

```
Memo {
  id, title, category,        // "shopping" | "restaurant" | "place" | "other" | custom
  tags: [string],
  priority,                   // "high" | "normal"

  savedAt
}

```

## Storage & Backup(仕様書6章)
- **IndexedDB** を主ストレージ(idb 等の薄いラッパー推奨)。localStorage は ViewSettings 等の軽量UI状態のみ
- `navigator.storage.persist()` を必ず呼ぶ(iOS Safari の自動削除対策)
- エクスポート: 全データ+スキーマバージョンを1つのJSONに書き出し、**Web Share API** で共有シートへ(非対応時はダウンロードにフォールバック)
- インポート: バージョン検証 → 置き換え/マージ選択 → 件数表示
- 最終エクスポートから90日でリマインド表示

## PWA Requirements(仕様書5章)
- Service Worker で全アセットをキャッシュし完全オフライン動作(店頭で電波が弱い前提)
- Web App Manifest: name "life-supporter"、display standalone、theme-color `#FAF6F0`(または `#D97757`)、192/512px アイコン
- サーバー・アカウント不要のローカルファースト
